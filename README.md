# ARIMA-LSTM Trading System

Author: *Jijun Chi*(1010253887), *Yingying Liu*(1008325974), *Yuchen Zhang* (1005693019), *Ke Yao*(1004883183)

In this project, we apply an ARIMA+LSTM model to predict stock correlations to enhance an algorithmic trading system based on PCA.

* ARIMA+LSTM Model
    * model in `model/arima_lstm_with_return.py`
    * pretrained model parameter in `epoch247.h5`
* Program
    * seed program: `Seeding_Trading_System.ipynb`, which is identical to provided code.
    * ARIMA+LSTM enhanved program: `ARIMA_LSTM_Trading_System`
* Data
    * `20industries_ETF_prc_UNSTACKED.csv`
    * `AGG_VTI_UNSTACKED_adjusted_returns.csv`
